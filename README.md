# Straddie Content Assets Kit

Static GitHub Pages tools for turning local media equipment notes into portable Markdown files.

The project sits beside the Strange but True `.md` family:

- `profile.md` for public identity
- `aura.md` for private capability context
- `public_noticeboard.md` for screen-safe public publishing
- grant/profile kits for funding and partner asks

## Pages

- `index.html` - brief guide and link hub
- `business-profile-builder.html` - export a standalone `business-profile.md`
- `film-club-builder.html` - export a starter `film-club.md`
- `asset-list-builder.html` - export an individual `asset-list.md`
- `shared-assets-builder.html` - export a team `shared-assets.md`
- `wishlist-builder.html` - export an `equipment-wishlist.md`
- `upgrade-roadmap-builder.html` - export an `upgrade-roadmap.md`
- `source-briefs.html` - summary of the source uploads used to seed the prompts

## Privacy

The builders run in the browser. They do not send form answers to a server.

Before publishing any generated Markdown, review it for private contact details, cultural permission, equipment locations, security details, and financial information.
