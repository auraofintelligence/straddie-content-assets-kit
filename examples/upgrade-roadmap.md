# Upgrade Roadmap

## Starting Point

Use personal tools, small events, phone clips, simple projection, Markdown files and manual review.

## Stage 1 - Use What I Have

Document the current kit, make phone-first templates, label folders, collect consent notes and keep public/private boundaries visible.

## Stage 2 - Use What We Have

Create a shared asset list, choose a steward, define borrowing rules, test a small event workflow and keep expensive or sensitive details private.

## Stage 3 - Reliable Local Production

Standardise audio, backups, run sheets, release notes, proxy files, event safety checks and grant evidence folders.

## Stage 4 - Evolving With The State Of The Art

Use AI assistants for planning, rough scripts, edit notes and metadata while keeping human approval, cultural review and local taste in control.
